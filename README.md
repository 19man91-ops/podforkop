# PodForkop

Форк [Podkop](https://github.com/itdoginfo/podkop) для маршрутизации трафика в OpenWrt с подписками на прокси и обходом секций для BitTorrent.

Направляйте нужные ресурсы в туннель, а остальное — напрямую. Открытое программное обеспечение на базе [sing-box](https://github.com/SagerNet/sing-box).

> [!WARNING]
> Проект находится в стадии бета-версии. Возможны ошибки, нестабильная работа и существенные изменения функциональности.

# Вещи, которые необходимо знать перед установкой

### Обновления и конфигурация
- При обновлении **обязательно** [очищайте кэш LuCI](https://podkop.net/docs/clear-browser-cache/).
- После обновления проверяйте конфигурацию — она может изменяться между версиями.
- При старте Podkop модифицируется конфигурация Dnsmasq.
- Podkop изменяет конфигурацию sing-box. Если вы используете собственную конфигурацию, заранее сохраните её.

### Системные требования
- Требуется OpenWrt 24.10 или выше.
- Необходимо минимум 25 МБ свободного места на устройстве. Устройства с флеш-памятью 16 МБ не поддерживаются.

### Важные ограничения и особенности
- Если установлен Getdomains, его [необходимо удалить](https://github.com/itdoginfo/domain-routing-openwrt?tab=readme-ov-file#скрипт-для-удаления)
- Dashboard доступен только при подключении по HTTP (из-за особенностей Clash API). При использовании HTTPS или домена работа может быть недоступна.

### Подписки на прокси

В секциях **Selector** и **URLTest** можно использовать прямые ссылки на прокси, HTTP(S)-ссылки на подписки или оба источника сразу. Для каждого типа достаточно заполнить хотя бы один список; если заполнены оба, ссылки объединяются. Поддерживаются подписки в виде обычного списка и Base64-списка URI VLESS, Trojan, Shadowsocks, SOCKS4/5 и Hysteria2. Интервал обновления задаётся общей настройкой **List and Subscription Update Frequency**. Если загрузка не удалась, текущий кэш подписки не перезаписывается.

### Прямой маршрут для BitTorrent

В общих настройках включите **Bypass sections for BitTorrent traffic**, чтобы распознанные BitTorrent-соединения между узлами и DHT шли напрямую до применения правил секций. HTTP(S)-запросы к трекерам не распознаются как P2P-соединения.

# Установка PodForkop
Полное руководство доступно в [документации](https://podkop.net/docs/install/)

Для установки и обновления достаточно выполнить один скрипт:
```
sh <(wget -O - https://raw.githubusercontent.com/19man91-ops/podforkop/main/install.sh)
```

Установщик автоматически устанавливает [podkop-engine](https://github.com/podkop-net/podkop-engine) под архитектуру роутера вместе с PodForkop. Это ядро предоставляет декодер ссылок, используемый для корректной обработки параметров Hysteria2, включая обфускацию и диапазоны портов. Если на роутере уже установлен `podkop-engine-full`, установщик обновляет именно этот вариант.
