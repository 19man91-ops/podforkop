# PodForCOP

Форк [Podkop](https://github.com/itdoginfo/podkop) для маршрутизации трафика в OpenWrt с подписками на прокси и обходом секций для BitTorrent.

Направляйте нужные ресурсы в туннель, а остальное — напрямую. Открытое программное обеспечение на базе [sing-box](https://github.com/SagerNet/sing-box).

> [!WARNING]
> Проект находится в стадии бета-версии. Возможны ошибки, нестабильная работа и существенные изменения функциональности.

# Вещи, которые необходимо знать перед установкой

### Обновления и конфигурация
- При обновлении **обязательно** [очищайте кэш LuCI](https://podkop.net/docs/clear-browser-cache/).
- После обновления проверяйте конфигурацию — она может изменяться между версиями.
- При старте Podkop модифицируется конфигурация Dnsmasq.
- Podkop изменяет конфигурацию sing-box. Если вы используете собственную конфигурацию, заранее сохраните её.

### Системные требования
- Требуется OpenWrt 24.10 или выше.
- Для базовой сборки `sing-box-forkop` установщику нужно около 45 МиБ эффективного свободного места; для `full` — около 55 МиБ. При обновлении установщик учитывает место, которое освободится после замены старого ядра. Устройства с флеш-памятью 16 МБ не поддерживаются.

### Важные ограничения и особенности
- Если установлен Getdomains, его [необходимо удалить](https://github.com/itdoginfo/domain-routing-openwrt?tab=readme-ov-file#скрипт-для-удаления)
- Dashboard доступен только при подключении по HTTP (из-за особенностей Clash API). При использовании HTTPS или домена работа может быть недоступна.

### Секции и точечная маршрутизация
- Направляйте нужные ресурсы в туннель, а остальное — напрямую через секции с гибкими правилами:
  - **Действия**: `Proxy`, `VPN`, `Bypass` (исключение/напрямую), `Block` (блокировка).
  - **Правила и списки**: встроенные списки сообщества (YouTube, Discord, Telegram, Instagram, Meta, Twitter, AI, региональные списки РКН/Geo), пользовательские домены, подсети и IP-адреса, локальные файлы правил и удалённые наборы правил (`.srs` / текст).
  - **Точечная привязка**: маршрутизация по портам, выборочно для конкретных локальных устройств (`fully_routed_ips`) или для всей домашней сети.
  - Включение/выключение секций переключателем прямо в таблице **Sections** без удаления конфигурации.

### Подключения и подписки
- **Подключения по прямым ссылкам**: VLESS (включая Reality, XTLS Vision, XHTTP, gRPC), Trojan, Shadowsocks (включая SS2022), Hysteria2 (`hysteria2://`, `hy2://`), TUIC, SOCKS, HTTP(S), а также VMess, AnyTLS и NaiveProxy.
- **Подписки всех основных форматов**: ссылка на подписку VPN-сервиса (HTTP/HTTPS) или локальный файл на роутере (например, `/etc/podkop/servers.txt`). Поддерживаются:
  - Списки прямых ссылок (plain list);
  - Списки в кодировке Base64;
  - Конфигурации Clash и Mihomo YAML;
  - Конфигурации sing-box JSON;
  - Конфигурации Xray JSON;
  - Профили SIP008.
- Подписки можно использовать как самостоятельный тип конфигурации (**Subscription**), а также в группах **Selector** и **URLTest** (с автовыбором самого быстрого сервера). Серверы протоколов, отсутствующих в выбранной сборке ядра, автоматически пропускаются.
- Удалённые подписки обновляются по расписанию (**List and Subscription Update Frequency**) и вручную командой `/usr/bin/podkop subscription_update`.

### Дашборд и мониторинг
- Отображение активного статуса всех секций и входящих в них серверов (включая серверы из подписок).
- Проверка задержки (Latency test) по каждому серверу и выбор активного узла в один клик.
- Мониторинг скорости трафика (Upload / Download), общего объёма переданных данных и активных соединений в реальном времени через Clash API.

### Прямой маршрут для BitTorrent

В общих настройках включите **Bypass sections for BitTorrent traffic**, чтобы распознанные BitTorrent-соединения между узлами и DHT шли напрямую до применения правил секций. HTTP(S)-запросы к трекерам не распознаются как P2P-соединения.

# Установка PodForCOP
Полное руководство доступно в [документации](https://podkop.net/docs/install/)

Для установки и обновления достаточно выполнить один скрипт:
```
sh <(wget -O - https://raw.githubusercontent.com/19man91-ops/podforkop/main/install.sh)
```

Установщик берёт пакеты PodForCOP и подходящий для архитектуры роутера пакет `sing-box-forkop` из зеркального релиза этого репозитория. Workflow зеркалирует официальные `.ipk` и `.apk` пакеты и SHA256 из [репозитория sing-box-forkop](https://github.com/ushan0v/sing-box-forkop); соответствующий исходный код и лицензия включены в зеркало. Этот core нужен для нативного разбора поддерживаемых форматов подписок и может заменить установленный `sing-box` или `podkop-engine` при обновлении.

По умолчанию устанавливается сборка `base`, где есть VMess и AnyTLS вместе с VLESS, Trojan, Shadowsocks, Hysteria2, TUIC и SOCKS. Для NaiveProxy и других протоколов полной сборки используйте:
```
PODFORCOP_FORKOP_VARIANT=full sh <(wget -O - https://raw.githubusercontent.com/19man91-ops/podforkop/main/install.sh)
```
