# Telegram Bridge для DeepSeek Harness

Двусторонний мост между чатами DeepSeek Harness и Telegram.

- **Harness → Telegram.** Каждое сообщение обычного чата (сессии) дублируется в Telegram.
  В форум-группе у каждого чата DSH — свой топик, поэтому список чатов в Telegram
  выглядит как список чатов в Harness.
- **Telegram → Harness.** Сообщение из Telegram попадает в выбранный чат DSH как
  обычный промпт пользователя; агент отвечает, ответ возвращается в Telegram.
  Работает даже при закрытом окне Harness, пока запущен процесс DSH.

## Настройка

1. Создайте бота: `@BotFather` → `/newbot` → получите токен вида
   `123456789:AA...`.
2. Положите токен в файл
   `C:\Users\<вы>\.dsh\telegram-bridge\token.txt` (одна строка, без кавычек).
   Плагин перечитывает файл на каждом цикле опроса — перезапуск не нужен.
3. Откройте чат с ботом и отправьте `/start <код привязки>`.
   Код задан в `cordis.patch.yml` (`pairingCode`). Он нужен, чтобы посторонний,
   нашедший бота, не получил доступ к агентам.
4. Готово: напишите что-нибудь боту.

Дополнительно можно завести группу, включить в ней **Topics** (это делает её
форум-супергруппой), добавить бота администратором с правом «Управление темами»
и отправить там `/start <код>`. Тогда каждый чат DSH автоматически получит
отдельный топик.

## Команды

| Команда | Действие |
|---|---|
| `/chats` | список чатов DSH (кнопки выбора/открытия топика) |
| `/new [название]` | создать новый чат DSH |
| `/status` | состояние моста |
| `/stop` | остановить текущий ход агента |
| `/title <текст>` | переименовать активный чат |
| `/mirror all\|active` | зеркалить все чаты или только активный |
| `/id` | id чата, пользователя, темы и сессии |
| `/help` | справка |

## Файлы и состояние

| Путь | Назначение |
|---|---|
| `~/.dsh/telegram-bridge/token.txt` | токен бота |
| `~/.dsh/telegram-bridge/state.json` | привязка, связки чат↔сессия, offset getUpdates |
| `~/.dsh/telegram-bridge/bridge.log` | журнал работы (для диагностики) |

Конфигурация плагина — в `cordis.patch.yml`: `pairingCode`, `mirrorMode`,
`autoLink`, `mirrorUserMessages`, опционально `tokenFile`, `stateDir`,
`defaultCwd`, `apiBase`, `pollTimeout`, `debug`.

## Ограничения

- Вложения из Telegram пока не принимаются (только текст).
- Ответ агента приходит одним сообщением после завершения хода; живой поток
  токенов не транслируется.
- Запросы подтверждения (approval) и структурированные вопросы агента
  (`ask_user_question`) по-прежнему обрабатываются в окне Harness.
