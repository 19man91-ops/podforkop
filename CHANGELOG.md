# Changelog

## 0.9.8

### Исправлено
- **Убран график трафика из Дашборда** (по замечанию: лишний элемент). Удалены соответствующая
  разметка, обновление истории, стили и тесты.
- **Кнопка «Скорость» на карточке узла теперь работает:** обработчик `click` вместо `onclick`,
  тест запускается через Clash API; при ошибке показывается уведомление, результат «N Mbps»/«N/A».
- **Исправлен egress IP для Privacy & Leak Test и speedtest:** `sing-box tools fetch` теперь запускается
  на минимальной копии конфига без inbound/Clash API (не конфликтует с запущенной службой),
  поэтому «main: недоступно» больше не должно появляться; при реальной ошибке всё равно показывается статус.
- **В модалке Privacy & Leak Test появилась кнопка «Закрыть»** (раньше приходилось обновлять страницу);
  добавлено оформление модального окна.
- **Убран «null» в карточке подписки** (фильтрация пустых дочерних элементов); исправлены подписи:
  «Использовано … · лимит не задан», «Действует до: не ограничен», источник показывается как
  `host +N` вместо списка с «(+N)».
- **Карточки подписок приведены к единому стилю** с виджетами Дашборда (общий бордер/радиус/отступы,
  единые строки, компактная кнопка обновления, flex-сетка без «дыр»).
- **Точная информация о ядре:** в «Системной информации» Диагностики теперь показывается
  пакет ядра (`sing-box-forkop` / `podkop-engine` / `sing-box`), семейство (`forkop`/`podkop-engine`/`sing-box`),
  вариант (`base`/`full`/`tiny`/`slim`/`stock`) и версия пакета ядра.

## 0.9.6

### Новое
- **uTLS-маскировка TLS-отпечатка (Anti-DPI).** В настройках секции появился выбор TLS-отпечатка
  (`Chrome`, `Firefox`, `Safari macOS/iOS`, `Edge`, `Randomized`). Podkop применяет `tls.utls` ко всем
  TLS-outbound этой секции, чтобы DPI видел обычный браузерный TLS ClientHello вместо прокси-трафика.
  Опция показывается только если ядро собрано с `with_utls` (forkop — всегда).
- **Privacy & Leak Test в Диагностике (одна кнопка):**
  - **DNS Leak Test** — проверяет, что dnsmasq направляет запросы в sing-box (`127.0.0.42`,
    `noresolv=1`), что системный resolv не смотрит на провайдера и что FakeIP отвечает;
  - **Egress IP & Geo по секциям** — для каждой активной прокси-секции запрашивает внешний IP и страну
    через выбранный outbound (`sing-box tools fetch -o <tag>`);
  - **MTU / MSS** — показывает MTU WAN/LAN, наличие MSS clamp, максимальный проходящий ping-пакет
    и рекомендует MSS (`MTU - 40`).

### Исправлено
- `sing_box_get_features` добавляет `tls.utls` только при реальной поддержке ядром.
- Новые строки переведены на русский; i18n-пайплайны синхронизированы.

## 0.9.5

### Новое
- **Привязка устройств к секциям (policy routing).** В настройках секции поле «Fully Routed IPs» теперь
  предлагает устройства из DHCP-аренды по именам (`POCO-F7 (192.168.1.23)`, `LG-WebOS-TV (...)`): выбранные
  клиенты направляются через маршрут этой секции. Можно по-прежнему вводить IP/подсети вручную.
- **Живой график скорости** в Дашборде: последние 40 замеров upload/download в виде столбчатых баров,
  обновляется из Clash API WebSocket (`/traffic`).
- **Добавление доменов из Мониторинга в 1 клик.** У каждого соединения с доменом появились кнопки
  «+» (добавить домен в выбранную секцию) и «⊘» (исключить домен из маршрутизации — создаётся/используется
  секция `exclusion`). Правила применяются автоматически (reload в фоне).
- **Тест скорости узлов (Download speedtest).** На карточке узла появилась кнопка «Speed»: скачивание
  тестового файла через выбранный outbound (`sing-box tools fetch -o <tag>`), результат в Мбит/с
  отображается прямо на карточке.
- **Telegram-уведомления.** Настройки (включение, bot token, chat ID) в разделе Settings:
  уведомления об истечении подписки (≤3 дней / истекла), неудачном обновлении подписок,
  недоступности прокси; тестовое уведомление — кнопкой в настройках или `podkop telegram_test`.
- **Улучшенное переключение сервера в Дашборде:** ошибки Clash API теперь показываются уведомлением,
  переключение остаётся мгновенным.

### Исправлено
- Уведомления и новые действия не ломают основной поток: сетевые вызовы ограничены по времени,
  повторные уведомления дедуплицируются.
- Токен Telegram-бота маскируется в `podkop show_config`.

## 0.9.4

### Новое
- **Виджет подписки в Дашборде (трафик и срок действия).** Для каждой секции с HTTP(S)-подпиской
  на Дашборде отображается карточка:
  - потребление трафика `upload + download` из стандартного заголовка
    `subscription-userinfo` (Marzban, 3X-UI, Remnawave, V2board, X-UI, Mihomo и др.);
  - прогресс-бар с цветами: зелёный → жёлтый (≥70%) → красный (≥90%);
  - «Трафик: X / Y», «Осталось: Z», «Действует до: дата», «Осталось дней: N»;
  - предупреждающий ярлык `⚠️ Скоро истекает` за 3 дня и `⚠️ Истекла` после окончания;
  - кнопка **Обновить** прямо на карточке и авто-обновление при устаревании кэша (>30 минут);
  - подпись «Обновлено: N мин назад».
- Новая CLI-команда `podkop subscription_info [refresh]` (JSON для UI/скриптов), данные
  кэшируются в `/etc/podkop/subscriptions/info.json`; в кэш попадает только host источника,
  полный URL подписки (с токеном) не сохраняется.
- `subscription_update` (ручное и по cron) теперь также обновляет данные для виджета.

### Исправлено
- Полные русские переводы для строк мониторинга соединений и нового виджета подписок
  (51+ msgid в обоих пайплайнах, включая ранее непереведённые строки Monitoring).
- `subscription_userinfo`-парсер устойчив к `X-Subscription-Userinfo`, отсутствию заголовка,
  локальным файлам и недоступным серверам (статусы `ok`/`partial`/`no-data`).

## 0.9.3

### Исправлено
- **Фальшивые возможности ядра для sing-box-forkop.** `sing_box_get_features` больше не объявляет
  `urltest.fallbacks`, `urltest.download_url` и `tools.decode-link` для forkop; UI скрывает
  неподдерживаемые настройки, а генератор конфига их пропускает. Раньше их включение давало
  невалидный JSON и Podkop не запускался.
- **`providers: []` на не-forkop ядрах.** Защита в `sing_box_cm_add_group_providers` теперь
  отсекает не только пустую строку, но и литерал `"[]"`; вызывающий код инициализирует
  теги провайдеров пустой строкой. Selector/URLTest больше не ломают `podkop-engine` и stock sing-box.
- **DNS failover на неподдерживающем ядре.** При нескольких DNS-серверах на не-forkop ядре
  используется первый сервер, а в лог пишется предупреждение вместо генерации невалидного конфига.
- **Утечка секретов в диагностике.** `show_sing_box_config` и `check_proxy` маскируют поле
  `link` parser-outbound и `providers[].url/path`.
- **Мониторинг, «Закрыть все».** Исправлен вызов несуществующего метода
  `closeAllClashApiConnections` (правильный — `closeClashApiConnections`).
- **Дашборд URL-подписок.** Сравнение типа Clash API `Selector` исправлено (было `selector`).
- **Двойной рестарт на Save & Apply.** Удалён дублирующий procd reload-trigger: остаётся один
  явный перезапуск из обработчика LuCI.
- **Drag & Drop.** При наличии штатного LuCI sortable используется он; собственная реализация
  остаётся только для старых LuCI. Двойные обработчики больше не конфликтуют.
- **Мёртвые команды.** Удалены несуществующие `main` и `check_sing_box_logs` из CLI и справки;
  добавлены рабочие `podkop enable` / `podkop disable`, а `podkop status` работает как
  псевдоним `get_status`.
- **Сообщение о версии sing-box** в диагностике использует `SB_REQUIRED_VERSION` вместо
  захардкоженного `1.12.4`.
- **`has_outbound_section`** учитывает флаг `enabled` секции.
- **TypeScript**: исправлены все ошибки `tsc --noEmit` (декларация `rpc`, типы ответов
  `MethodResponse`, `ConfigSection.label`, `getSingBoxFeatures`).

### Улучшено
- **Безопасность установщика**: убран `--no-check-certificate` (TLS проверяется всегда),
  `SHA256SUMS` обязателен и проверяется для всех пакетов, установка прерывается при ошибке
  установки любого пакета, выполняется финальная проверка `podkop`/`luci-app-podkop`.
- **Автозапуск**: установщик выполняет `/etc/init.d/podkop enable`, поэтому служба переживает
  перезагрузку; итоговое сообщение подсказывает открыть LuCI и нажать Save & Apply.
- **`update-fast.sh`** переписан: staging-каталог, все файлы (включая `monitoring.js`,
  `dashboard.js`, `diagnostic.js` и все библиотеки), правильные пути `/usr/lib/podkop/`,
  источники из тега установленной версии, TLS без отключения проверки.
- **Кэш подписок**: для forkop включён `cache_file.store_subscriptions` — провайдеры
  поднимаются из кэша при недоступности сервера подписок.
- **CI**: добавлены `tsc --noEmit` и `prettier --check`, используется `yarn install --frozen-lockfile`,
  добавлена проверка соответствия git-тега и `VERSION`.
- **Локализация**: добавлены 13 отсутствовавших msgid (Mode, Monitoring, Proxy, VPN, Block,
  Exclusion, строки модального окна применения и др.) в pot/po обоих пайплайнов.
- **Документация**: README исправлен (GPL-2.0-or-later, `podkop get_status`, opkg 24.10 / apk 25.12+,
  автозапуск, ограничения альтернативного ядра), добавлена атрибуция шрифта Twemoji (CC-BY 4.0).
