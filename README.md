# PodForCOP

**PodForCOP** — это форк [Podkop](https://github.com/itdoginfo/podkop) для OpenWrt с интеграцией расширенного ядра [sing-box-forkop](https://github.com/ushan0v/sing-box-forkop). Проект создан для удобной, точечной маршрутизации трафика через VPN и прокси с поддержкой любых форматов подписок, современных протоколов, интерактивного управления секциями и мониторинга в реальном времени.

Направляйте нужные ресурсы в туннель, а остальной трафик — напрямую без потери скорости.

---

## 🚀 Ключевые возможности

### 1. 🔄 Перетаскивание секций мышью (Drag & Drop)
* Управление приоритетом правил маршрутизации простым перетаскиванием строк таблицы секций мышью (сверху вниз — первое совпадение побеждает).
* Визуальная подсветка целевой позиции при перетаскивании.
* Быстрый чекбокс **«✔ Включено»** в таблице для мгновенного отключения или включения секции без удаления её настроек.

### 2. ⚡ Автоматический запуск при сохранении
* Больше не нужно заходить в пункт «Диагностика» для ручного запуска!
* При нажатии **«Save & Apply»** («Сохранить и применить») служба Podkop автоматически сохраняет конфигурацию, перезапускается и сразу начинает маршрутизацию.
* Системный сервис `procd` отслеживает изменения конфигурации и поддерживает службу в активном состоянии.

### 3. 🌐 Подписки всех форматов
* Поддержка ссылок на подписки любого VPN-провайдера (HTTP/HTTPS) или локальных файлов со списком узлов на роутере (например, `/etc/podkop/servers.txt`).
* **Все основные форматы «из коробки»**:
  * Списки в кодировке **Base64**;
  * Конфигурации **Clash** и **Mihomo YAML**;
  * Конфигурации **sing-box JSON**;
  * Конфигурации **Xray JSON**;
  * Профили **SIP008**;
  * Списки прямых ссылок (plain list).
* Подписки можно использовать:
  * как отдельный тип подключения (**Subscription**);
  * в группе **Selector** (ручное переключение серверов на Дашборде);
  * в группе **URLTest** (автоматический выбор сервера с наименьшей задержкой).
* Автоматическое обновление подписок по расписанию и вручную по кнопке или команде `/usr/bin/podkop subscription_update`.

### 4. 🛡️ Поддержка современных протоколов
* **VLESS** (включая Reality, XTLS Vision, XHTTP, gRPC);
* **Trojan**;
* **Shadowsocks** (включая современный Shadowsocks 2022);
* **Hysteria 2** (`hysteria2://`, `hy2://`);
* **TUIC**;
* **AnyTLS**, **VMess**, **SOCKS5**, **HTTP(S)**;
* **NaiveProxy** (в сборке ядра `full`).

### 5. 🎯 Точечная маршрутизация по правилам и секциям
* **Списки сообщества**: готовые наборы правил (YouTube, Discord, Telegram, Instagram, Meta, Twitter, зарубежные AI-сервисы, антиблокировочные списки РКН и GeoIP).
* **Пользовательские списки**: домены, IP-адреса, CIDR-подсети, локальные текстовые файлы и наборы правил `.srs`.
* **Маршрутизация клиентов (`fully_routed_ips`)**: перенаправление всего трафика выбранных домашних устройств (Smart TV, консоли, рабочие ПК) через туннель.
* **Действия над трафиком**: `Proxy`, `VPN`, `Bypass` (напрямую) и `Block` (блокировка).

### 6. 📊 Дашборд и мониторинг соединений
* Отображение активных узлов подписок с проверкой пинга (latency) в один клик.
* Ручное переключение серверов прямо из веб-интерфейса.
* Мониторинг скорости (Upload / Download) и активных соединений в реальном времени через Clash API.

### 7. 📥 Прямой маршрут для BitTorrent
* Опция **«Bypass sections for BitTorrent traffic»** в общих настройках позволяет пускать P2P-трафик торрентов напрямую в обход VPN, защищая туннель от перегрузки.

## 📦 Установка и обновление

Установщик полностью автоматизирован, не зависит от лимитов GitHub API и корректно заменяет старые ядра как на OpenWrt с пакетным менеджером `apk` (OpenWrt 24.10, 25.12+), так и со старым `opkg`.

### Стандартная установка (рекомендуется):

Выполните команду в терминале роутера (SSH):

```sh
sh <(wget -O - https://raw.githubusercontent.com/19man91-ops/podforkop/main/install.sh)
```

По умолчанию устанавливается сборка ядра `base` (включает VLESS, Trojan, Shadowsocks-2022, Hysteria 2, TUIC, AnyTLS, VMess, SOCKS).

### Установка с максимальным набором протоколов (`full`):

Если вам требуется поддержка NaiveProxy и редких протоколов:

```sh
PODFORCOP_FORKOP_VARIANT=full sh <(wget -O - https://raw.githubusercontent.com/19man91-ops/podforkop/main/install.sh)
```

## ⚡ Быстрое обновление интерфейса (без переустановки)

Если PodForCOP уже установлен, применить последние изменения LuCI (перетаскивание строк и автозапуск) можно за 2 секунды:

```sh
wget -O /www/luci-static/resources/view/podkop/podkop.js https://raw.githubusercontent.com/19man91-ops/podforkop/main/luci-app-podkop/htdocs/luci-static/resources/view/podkop/podkop.js && \
wget -O /www/luci-static/resources/view/podkop/main.js https://raw.githubusercontent.com/19man91-ops/podforkop/main/luci-app-podkop/htdocs/luci-static/resources/view/podkop/main.js && \
wget -O /etc/init.d/podkop https://raw.githubusercontent.com/19man91-ops/podforkop/main/podkop/files/etc/init.d/podkop && \
chmod +x /etc/init.d/podkop && \
rm -f /tmp/luci-indexcache* /tmp/luci-modulecache* && \
/etc/init.d/uhttpd restart && \
/etc/init.d/rpcd restart
```

## 🛠️ Системные требования

* **OpenWrt 24.10, 25.12 или новее** (поддерживаются все популярные архитектуры: `aarch64_cortex-a53`, `x86_64`, `mipsel`, `mips` и др.).
* Свободное место во flash-памяти: от ~45 МиБ для сборки `base` (установщик учитывает место, освобождаемое при замене старого ядра).
* Роутеры с 16 МБ Flash без внешнего накопителя (extroot) не поддерживаются из-за размера современных Go-ядер.
* Если был установлен `Getdomains`, удалите его перед установкой во избежание конфликтов таблиц nftables.

## 📖 Быстрый старт

1. Откройте панель управления LuCI: `http://192.168.1.1` ➔ **Службы** ➔ **Podkop** *(нажмите `Ctrl + F5` для обновления кэша интерфейса)*.
2. **Добавление подписки**:
   - Перейдите на вкладку **Секции** (Sections).
   - Нажмите **Редактировать** (Edit) у секции `main` (или создайте новую секцию через поле «Добавить секцию»).
   - В поле **Тип подключения** выберите `Proxy`.
   - В поле **Тип конфигурации** выберите `Подписка` (Subscription).
   - Вставьте URL вашей подписки (например, `https://your-domain.org:2096/...`) или путь к файлу `/etc/podkop/servers.txt`.
   - В блоке **Списки сообщества** выберите нужные сервисы (YouTube, Discord и др.) или укажите свои домены.
   - Нажмите **Сохранить** (Save) в модальном окне.
3. **Приоритет правил**:
   - На вкладке «Секции» перетащите нужную секцию выше или ниже, зажав строку мышью.
4. **Применение**:
   - Нажмите **Save & Apply** внизу страницы. Служба автоматически запустится с новой конфигурацией.
5. **Проверка**:
   - Откройте вкладку **Дашборд** (Dashboard), чтобы увидеть активные ноды, замерить пинг и выбрать оптимальный сервер.

## 🔍 Управление и диагностика в консоли

```sh
# Проверка версии ядра и активной сборки
sing-box version

# Проверка статуса службы
podkop status

# Принудительное обновление подписок
podkop subscription_update

# Просмотр логов работы службы
logread -e podkop
```
